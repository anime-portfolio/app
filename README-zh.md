# Anime Portfolio

一个开发者作品集模板，附带两位原创水彩角色，各自拥有一套主题：明亮的 Crystalline，以及深色的 Weltschmerz。

[![Live demo](https://img.shields.io/badge/demo-live-brightgreen)](https://anime-portfolio.github.io/app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 主题与角色

Crystalline 是明亮主题，由柔和的水彩蓝与淡紫色构成。它的伙伴是 Crystalline-chan，一个与玻璃鹿同行的女孩。

Weltschmerz 是深色主题，安静而沉重，由深紫与墨色构成。它的伙伴是 Weltschmerz-chan，一个感受着世界重量的女孩。

两位角色及其插画均为 Aesthetic Vulpes（didvc）的原创作品。页头的切换按钮可以在两个主题之间切换。

## 功能

当前主题的角色会漂浮在页面角落，不时说出一句短语，被点击时也会说话。页面以故障（glitch）风格的转场切换，加载时会显示 ASCII 动画，卡片会随鼠标轻微移动，还有一个终端风格的界面，可以用命令浏览项目。另外藏有几个彩蛋，包括一组隐藏的按键序列（↑ ↑ ↓ ↓ ← → ← → B A）。界面支持英文和日文，并有一个小型 wiki 收录帮助和隐私页面。

## 适合谁

Anime Portfolio 适合想要一个真正“有角色”的个人网站的开发者。尤其适合：

- 需要一个让人看过一次就记住的作品集的网页开发者、设计师和学生
- 也会写代码、想让自己的画成为网站一部分的插画师和业余画手
- 日本的开发者，或在日本与世界各地之间工作、想要英日双语作品集又不想维护两个网站的人
- 想在 GitHub Pages 上免费搭建静态作品集，不需要服务器、数据库或月费的人

如果你正在寻找动漫风格的开发者作品集模板、可爱（kawaii）风格的作品集，或是带有深色和浅色模式的 Next.js 作品集，这就是为此而做的，而且细节都已经打磨好了。

## 理念

大多数作品集模板看起来都差不多：主视觉横幅、卡片网格、联系表单。它们能用，但访客很快就忘了。这个模板保留了好用的部分，也就是项目网格、个人简介和链接，再加上一个住在页面上的小伙伴。点击她会有反应，她会不时说一句话，并随主题改变样貌。这是一种不干扰作品、又能安静展现个性的方式。

两个主题不只是两套配色，而是两种心情。Crystalline 明亮清澈，像白天光线中的玻璃。Weltschmerz（德语，意为看清世界本来面目之后的倦怠与哀伤）则深沉安静，像深夜里慢慢变干的墨水。访客只要点一下就能切换，角色、配色和台词的语气会一起改变。

角色都是原创的。许多粉丝制作的模板借用了现有动画的角色，让每个使用者都处在灰色地带。Crystalline-chan 和 Weltschmerz-chan 是为这个项目绘制的，并以开放许可发布，你可以放心地以她们为基础创作，或换成自己的角色，不必担心版权归属。

## 打造成你自己的

这个模板的设计让你不必了解整体原理，也能修改真正重要的部分。

### 你的角色

每个主题都有一位漂浮角色。你可以保留 Crystalline-chan 和 Weltschmerz-chan，也可以换成自己的画、吉祥物、你家猫咪的照片，或者什么都不放。理想的角色图片是背景透明的 PNG，大约 300×450 像素，并且在屏幕角落缩小显示时依然清晰。水彩、线稿和像素画都很合适；页面不会加外框，你画的内容会直接漂浮在网站上。

如果不想要角色，任一主题都可以关闭漂浮伙伴，网站其他部分的运行完全不受影响。

### 她的台词

每位角色都有一组简短的台词，会随机说出，或在访客点击时说出。个性大多来自这里。几点建议：

- 保持简短。对话框里一句话最合适，两句是极限。
- 配合主题。Crystalline-chan 留意的是光与色彩；Weltschmerz-chan 留意的是重量与寂静。
- 让台词引导方向。像“让我给你看些闪闪发亮的东西……”这样的台词，会引导访客向下滚动。
- 为隐藏的按键序列写一句台词。找到它的访客会看到特别消息，所以让它值得被找到。

### 两个主题，两种心情

你可以重命名主题、更改配色，或加入第三个主题。一组对比，例如白天与夜晚、平静与喧闹、工作与玩乐，通常比两套相似的配色更有意图。无论选择什么，都要让两个主题中的文字清晰易读：切换只需点一下，访客两个都会看到。

### 会讲故事的项目

项目网格有三种视图：精选、全部项目和实验性。精选放的是你在面试时最想先展示的作品。实验性则放那些古怪、未完成却充满乐趣、能体现你思考方式的东西；很多访客觉得这一栏最有意思。每个项目可以有多张截图、标签、演示链接和源码链接，以及卡片用的一行摘要和较长的说明。

### 英文与日文

网站上的每个标签都有英文和日文版本，访客可以从页头切换语言。你的名字、职位、所在地和简介也可以准备两种语言。这让模板很适合做双语作品集、在日本求职，或同时向两类读者展示作品。

### 终端

为喜欢键盘的访客，网站内置了一个小型终端。输入 `help` 会列出命令；`ls` 列出你的项目，`featured` 和 `experimental` 切换网格，`clear` 清空屏幕，`exit` 关闭终端。这只是个小巧思，但开发者往往会发现并乐在其中。

## 技术栈

Next.js 15（App Router，导出为静态网站）、React 19、TypeScript、Tailwind CSS 3、Framer Motion，以及 shadcn/ui 风格的 Radix UI 组件和 Lucide 图标。演示网站托管在 GitHub Pages 上。

## 快速开始

需要 Node.js 18.18 或更高版本，以及 npm 或 pnpm。

1. 克隆仓库：
   ```bash
   git clone https://github.com/anime-portfolio/app.git
   cd app
   ```

2. 安装依赖：
   ```bash
   npm install
   # or
   pnpm install
   ```

3. 启动开发服务器：
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

4. 打开 [http://localhost:3000](http://localhost:3000)。

### 构建

```bash
npm run build
```

网站会以静态文件导出到 `out/`。如果要从子路径提供服务，例如 GitHub Pages 上的 `/app/`，请在构建时设置 `PAGES_BASE_PATH=/app`。

## 自定义

### 个人资料

编辑 `data/portfolio-data.tsx`：

```typescript
export const profileData: ProfileData = {
  name: {
    en: "Your Name",
    ja: "あなたの名前",
  },
  role: {
    en: "Your Role",
    ja: "あなたの役割",
  },
  // ... more configuration
}
```

社交链接和联系邮箱都是可选的；页面只会显示已设置的项。

### 项目

在同一个文件的 `works` 数组中添加你的项目：

```typescript
{
  id: "your-project",
  title: "Project Title",
  description: "Project description...",
  images: ["image1.jpg", "image2.jpg"],
  link: "https://your-project.com",
  repo: "https://github.com/your-username/project",
  tags: ["React", "TypeScript", "Next.js"],
  date: "2024-12",
  featured: true,
}
```

### 主题

两个主题位于 `contexts/theme-context.tsx`。新主题就是另一份相同结构的配置，搭配自己的配色和漂浮角色：

```typescript
export const customTheme: PortfolioPageProperties = {
  type: "fullscreen",
  styles: ["anime", "custom"],
  gradientBg: "bg-gradient-to-br from-custom-900 to-custom-100",
  // ... more customization
}
```

## 部署

演示网站通过 `.github/workflows/pages.yml` 部署到 GitHub Pages，每次推送到 `master` 时都会构建并发布网站。导出的 `out/` 文件夹也可以在 Vercel、Netlify 或任何静态托管上运行。

### 在 GitHub Pages 发布你自己的版本

由于网站导出为纯静态文件，托管是免费的，也不需要服务器：

1. Fork 这个仓库，或把它作为模板创建新仓库。
2. 在仓库设置中打开 Pages，并选择 GitHub Actions 作为来源。
3. 推送一个改动到 `master` 分支。自带的工作流会构建网站，并发布到 `https://your-username.github.io/your-repository/`。

如果你从名为 `your-username.github.io` 的仓库发布，网站会位于该地址的根目录。自定义域名也可以在同一个 Pages 设置中添加。之后每次推送都会自动重新构建并发布，所以更新作品集只需要编辑文件并推送。

## 常见问题

### 可以免费使用吗？

可以。代码采用 MIT 许可证，你可以用于个人网站、客户项目或商业产品，并随意修改。

### 我可以在自己的网站上使用 Crystalline-chan 和 Weltschmerz-chan 吗？

可以。角色插画采用 CC BY 4.0 许可，只要注明出处，就可以使用、修改和再分发，包括商业用途。在页脚或 README 中加上一行 "Characters: Crystalline-chan and Weltschmerz-chan by Aesthetic Vulpes (CC BY 4.0)" 即可。

### 需要懂 React 或 Next.js 吗？

基本使用不需要。你的名字、简介、链接、项目和角色台词都放在简单的数据文件里，读起来几乎像一张表单。修改布局或添加新功能则需要一些 React 知识。

### 需要服务器或数据库吗？

不需要。网站导出为静态的 HTML、CSS 和 JavaScript，可以免费运行在 GitHub Pages、Netlify、Vercel、Cloudflare Pages 或任何普通网页主机上。

### 手机上能用吗？

可以。布局是响应式的，小屏幕上导航会收起为菜单，角色也不会挡住内容。

### 可以去掉动漫元素，当作普通作品集吗？

可以。关闭漂浮角色、选择更沉稳的配色，剩下的就是一个简洁快速的开发者作品集，包含项目网格、个人简介、两个主题和双语支持。

### 可以在这里分享我的作品集吗？

非常欢迎。请到 [Discussions](https://github.com/anime-portfolio/app/discussions) 分享；看到大家如何把它变成自己的，是维护模板最开心的事。
