# Anime Portfolio

2人のオリジナル水彩キャラクターと、それぞれのテーマを備えた開発者向けポートフォリオテンプレートです。明るいテーマ「Crystalline」と、暗いテーマ「Weltschmerz」があります。

[![Live demo](https://img.shields.io/badge/demo-live-brightgreen)](https://anime-portfolio.github.io/app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## テーマとキャラクター

Crystalline は、やわらかな水彩の青とライラックでまとめた明るいテーマです。相棒は、ガラスでできた鹿と歩く女の子、クリスタリンちゃん（Crystalline-chan）です。

Weltschmerz は、深い紫とインクでまとめた、静かで重たい暗いテーマです。相棒は、世界の重さを感じている女の子、ヴェルトシュメルツちゃん（Weltschmerz-chan）です。

2人のキャラクターとそのイラストは、Aesthetic Vulpes（didvc）によるオリジナル作品です。ヘッダーのスイッチで2つのテーマを切り替えられます。

## 機能

現在のテーマのキャラクターがページの隅に浮かび、ときどき、あるいはクリックされたときに短いセリフを話します。ページはグリッチ風のトランジションで切り替わり、読み込み中はASCIIアニメーションが表示されます。カードはマウスに合わせてわずかに動き、ターミナル風のインターフェースからコマンドでプロジェクトを閲覧できます。隠しキー入力（↑ ↑ ↓ ↓ ← → ← → B A）をはじめ、いくつかの隠し要素もあります。表示は英語と日本語に対応し、小さなウィキにヘルプとプライバシーのページがあります。

## こんな人に

Anime Portfolio は、文字どおり「キャラクター」のある個人サイトがほしい開発者のためのテンプレートです。たとえば次のような人に向いています。

- 一度見たら覚えてもらえるポートフォリオがほしいWeb開発者、デザイナー、学生
- コードも書くイラストレーターや趣味の絵描きで、自分の絵をサイトの一部にしたい人
- 日本の開発者や、日本と海外をまたいで働く人で、2つのサイトを管理せずに英語と日本語のバイリンガルなポートフォリオを持ちたい人
- サーバーもデータベースも月額料金もなしに、GitHub Pages で無料の静的ポートフォリオを公開したい人

アニメ風の開発者ポートフォリオテンプレート、かわいい（kawaii）ポートフォリオ、ダークモードとライトモードのある Next.js ポートフォリオを探していたなら、このテンプレートがまさにそれです。細かな粗も、あらかじめ整えてあります。

## コンセプト

多くのポートフォリオテンプレートは、ヒーローバナー、カードのグリッド、問い合わせフォームと、どれも似た見た目です。役には立ちますが、訪問者の記憶には残りません。このテンプレートは、プロジェクトの一覧、プロフィール、リンクといった役に立つ部分はそのままに、ページに住む小さな相棒を加えています。クリックすると反応し、ときどきセリフを話し、テーマに合わせて姿を変えます。作品の邪魔をせずに、さりげなく個性を見せる方法です。

2つのテーマは、単なる配色の違いではなく、2つの気分です。Crystalline は、昼の光の中のガラスのように明るく澄んでいます。Weltschmerz（世界をありのままに見ることからくる倦怠と悲しみを表すドイツ語）は、夜更けに乾いていくインクのように暗く静かです。訪問者はワンクリックで切り替えられ、キャラクター、配色、セリフの雰囲気が一緒に変わります。

キャラクターはオリジナルです。ファンが作るテンプレートの多くは既存のアニメのキャラクターを借りていて、使う人すべてをグレーな立場に置いてしまいます。クリスタリンちゃんとヴェルトシュメルツちゃんはこのプロジェクトのために描かれ、オープンなライセンスで公開しているので、誰のものかを気にせずに使ったり、自分のキャラクターに差し替えたりできます。

## 自分のものにする

このテンプレートは、全体の仕組みを学ばなくても、大事な部分だけを変えられるように作られています。

### あなたのキャラクター

各テーマには浮かぶキャラクターが1人ずついます。クリスタリンちゃんとヴェルトシュメルツちゃんをそのまま使っても、自分の絵やマスコット、飼い猫の写真に替えても、何も置かなくても構いません。キャラクター画像は、背景が透明なPNGで、300×450ピクセル前後、画面の隅に小さく表示されても見やすいように描かれたものが適しています。水彩、線画、ドット絵のどれでも合います。ページは枠を付けないので、描いたものがそのままサイトの上に浮かびます。

キャラクターを置きたくない場合は、どちらのテーマでも浮かぶ相棒をオフにでき、サイトのほかの部分はまったく同じように動きます。

### 彼女のセリフ

各キャラクターは短いセリフのリストを持ち、ランダムに、あるいは訪問者にクリックされたときに話します。個性の大部分はここから生まれます。いくつかのヒントです。

- 短くまとめる。吹き出しには1文がちょうどよく、2文が限度です。
- テーマに合わせる。クリスタリンちゃんは光や色に気づき、ヴェルトシュメルツちゃんは重さや静けさに気づきます。
- どこかへ誘う。「キラキラしたものを見せてあげる…」のようなセリフは、訪問者にスクロールを促します。
- 隠しキー入力用のセリフを書く。見つけた人には特別なメッセージが表示されるので、見つける価値のあるものにしましょう。

### 2つのテーマ、2つの気分

テーマの名前を変えたり、色を変えたり、3つ目を加えたりできます。昼と夜、静と動、仕事と遊びのような対になる組み合わせは、似た配色を2つ並べるより意図がはっきり伝わります。どんな組み合わせでも、両方で文字が読みやすいようにしてください。切り替えはワンクリックなので、訪問者は両方を目にします。

### 物語のあるプロジェクト

プロジェクト一覧には、注目作品、全プロジェクト、実験的の3つの表示があります。注目作品は、面接で最初に見せたい仕事のための場所です。実験的は、あなたの考え方が表れる、風変わりで未完成で楽しいもののための場所で、多くの訪問者がいちばん興味を持つのはここです。各プロジェクトには、複数のスクリーンショット、タグ、デモへのリンクとソースへのリンク、カード用の1行の要約と、より長い説明を付けられます。

### 英語と日本語

サイトのすべての表示は英語と日本語に対応していて、訪問者はヘッダーから言語を切り替えられます。名前、役割、所在地、自己紹介にも両方の言語を用意できます。バイリンガルのポートフォリオや日本での就職活動、両方の読者に同時に作品を見せたいときにぴったりです。

### ターミナル

キーボード派の訪問者のために、小さなターミナルも用意しています。`help` と入力するとコマンドの一覧が表示されます。`ls` でプロジェクトの一覧、`featured` と `experimental` で表示の切り替え、`clear` で画面の消去、`exit` で終了です。小さな仕掛けですが、開発者はよく見つけて楽しんでくれます。

## 技術スタック

Next.js 15（App Router、静的サイトとして書き出し）、React 19、TypeScript、Tailwind CSS 3、Framer Motion、shadcn/ui スタイルの Radix UI コンポーネント、Lucide アイコン。デモは GitHub Pages でホストしています。

## クイックスタート

Node.js 18.18 以降と、npm または pnpm が必要です。

1. リポジトリをクローンします:
   ```bash
   git clone https://github.com/anime-portfolio/app.git
   cd app
   ```

2. 依存関係をインストールします:
   ```bash
   npm install
   # or
   pnpm install
   ```

3. 開発サーバーを起動します:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

4. [http://localhost:3000](http://localhost:3000) を開きます。

### ビルド

```bash
npm run build
```

サイトは静的ファイルとして `out/` に書き出されます。GitHub Pages の `/app/` のようなサブパスで公開する場合は、ビルド時に `PAGES_BASE_PATH=/app` を設定します。

## カスタマイズ

### プロフィール

`data/portfolio-data.tsx` を編集します:

```typescript
export const profileData: ProfileData = {
  name: {
    en: "Your Name",
    ja: "あなたの名前",
  },
  role: {
    en: "Your Role",
    ja: "あなたの役割",
  },
  // ... more configuration
}
```

SNSのリンクと連絡先のメールアドレスは任意で、設定したものだけがページに表示されます。

### プロジェクト

同じファイルの `works` 配列にプロジェクトを追加します:

```typescript
{
  id: "your-project",
  title: "Project Title",
  description: "Project description...",
  images: ["image1.jpg", "image2.jpg"],
  link: "https://your-project.com",
  repo: "https://github.com/your-username/project",
  tags: ["React", "TypeScript", "Next.js"],
  date: "2024-12",
  featured: true,
}
```

### テーマ

2つのテーマは `contexts/theme-context.tsx` にあります。新しいテーマは、同じ形の設定を独自の色と浮かぶキャラクターで追加するだけです:

```typescript
export const customTheme: PortfolioPageProperties = {
  type: "fullscreen",
  styles: ["anime", "custom"],
  gradientBg: "bg-gradient-to-br from-custom-900 to-custom-100",
  // ... more customization
}
```

## デプロイ

デモは `.github/workflows/pages.yml` によって GitHub Pages にデプロイされ、`master` へのプッシュのたびにサイトがビルドされて公開されます。書き出された `out/` フォルダは、Vercel、Netlify、その他の静的ホスティングでも動きます。

### 自分のコピーを GitHub Pages で公開する

サイトは素の静的ファイルとして書き出されるので、ホスティングは無料で、サーバーも不要です。

1. このリポジトリをフォークするか、テンプレートとして新しいリポジトリを作ります。
2. リポジトリの設定で Pages を開き、ソースに GitHub Actions を選びます。
3. `master` ブランチに変更をプッシュします。付属のワークフローがサイトをビルドし、`https://your-username.github.io/your-repository/` で公開します。

`your-username.github.io` という名前のリポジトリから公開する場合、サイトはそのアドレスのルートに置かれます。独自ドメインも同じ Pages の設定から追加できます。以後のプッシュのたびにサイトは自動で再ビルドされて公開されるので、ポートフォリオの更新はファイルを編集してプッシュするだけです。

## よくある質問

### 無料で使えますか？

はい。コードは MIT ライセンスなので、個人サイト、クライアントのプロジェクト、商用製品のどれにでも使え、自由に変更できます。

### クリスタリンちゃんとヴェルトシュメルツちゃんを自分のサイトで使えますか？

はい。キャラクターのイラストは CC BY 4.0 で公開していて、クレジットを表記すれば、商用を含めて利用、改変、再配布ができます。フッターや README に "Characters: Crystalline-chan and Weltschmerz-chan by Aesthetic Vulpes (CC BY 4.0)" のような1行があれば十分です。

### React や Next.js の知識は必要ですか？

基本的な使い方なら必要ありません。名前、自己紹介、リンク、プロジェクト、キャラクターのセリフは、どれもフォームのように読めるシンプルなデータファイルにまとまっています。レイアウトの変更や新機能の追加には、多少の React の知識が必要です。

### サーバーやデータベースは必要ですか？

いいえ。サイトは静的な HTML、CSS、JavaScript として書き出されるので、GitHub Pages、Netlify、Vercel、Cloudflare Pages など、一般的なWebホスティングで無料で動きます。

### スマートフォンでも使えますか？

はい。レイアウトはレスポンシブで、小さな画面ではナビゲーションがメニューにまとまり、キャラクターもコンテンツの邪魔にならない位置にとどまります。

### アニメ要素を外して、シンプルなポートフォリオとして使えますか？

はい。浮かぶキャラクターをオフにして落ち着いた色を選べば、プロジェクト一覧、プロフィール、2つのテーマ、バイリンガル対応を備えた、すっきりと速い開発者ポートフォリオになります。

### 自分のポートフォリオを紹介してもいいですか？

ぜひどうぞ。[Discussions](https://github.com/anime-portfolio/app/discussions) で共有してください。みなさんがどう自分のものにしているかを見るのが、テンプレートをメンテナンスするいちばんの楽しみです。
