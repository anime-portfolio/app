# Anime Portfolio

一個開發者作品集範本，附有兩位原創水彩角色，各自擁有一套主題：明亮的 Crystalline，以及深色的 Weltschmerz。

[![Live demo](https://img.shields.io/badge/demo-live-brightgreen)](https://anime-portfolio.github.io/app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 主題與角色

Crystalline 是明亮主題，以柔和的水彩藍與淡紫色構成。它的夥伴是 Crystalline-chan，一個與玻璃鹿同行的女孩。

Weltschmerz 是深色主題，安靜而沉重，以深紫與墨色構成。它的夥伴是 Weltschmerz-chan，一個感受著世界重量的女孩。

兩位角色及其插畫皆為 Aesthetic Vulpes（didvc）的原創作品。頁首的切換按鈕可在兩個主題之間切換。

## 功能

目前主題的角色會漂浮在頁面角落，不時說出一句短語，被點擊時也會說話。頁面以故障（glitch）風格的轉場切換，載入時會顯示 ASCII 動畫，卡片會隨滑鼠輕微移動，還有一個終端機風格的介面，可以用指令瀏覽專案。另外藏有幾個彩蛋，包括一組隱藏的按鍵序列（↑ ↑ ↓ ↓ ← → ← → B A）。介面支援英文與日文，並有一個小型 wiki 收錄說明與隱私權頁面。

## 適合誰

Anime Portfolio 適合想要一個真正「有角色」的個人網站的開發者。特別適合：

- 需要一個讓人看過一次就記住的作品集的網頁開發者、設計師與學生
- 也會寫程式、想讓自己的畫成為網站一部分的插畫家與業餘繪師
- 日本的開發者，或在日本與世界各地之間工作、想要英日雙語作品集又不想維護兩個網站的人
- 想在 GitHub Pages 上免費架設靜態作品集，不需要伺服器、資料庫或月費的人

如果你正在尋找動漫風格的開發者作品集範本、可愛（kawaii）風格的作品集，或是具備深色與淺色模式的 Next.js 作品集，這就是為此而做的，而且細節都已經打磨好了。

## 理念

大多數作品集範本看起來都差不多：主視覺橫幅、卡片網格、聯絡表單。它們能用，但訪客很快就忘了。這個範本保留了好用的部分，也就是專案網格、個人簡介與連結，再加上一個住在頁面上的小夥伴。點擊她會有反應，她會不時說一句話，並隨主題改變樣貌。這是一種不干擾作品、又能安靜展現個性的方式。

兩個主題不只是兩套配色，而是兩種心情。Crystalline 明亮清澈，像白天光線中的玻璃。Weltschmerz（德語，意指看清世界本來面目後的倦怠與哀傷）則深沉靜謐，像深夜裡慢慢乾去的墨水。訪客只要點一下就能切換，角色、配色與台詞的語氣會一起改變。

角色都是原創的。許多粉絲製作的範本借用了既有動畫的角色，讓每個使用者都處在灰色地帶。Crystalline-chan 與 Weltschmerz-chan 是為這個專案繪製的，並以開放授權釋出，你可以放心地以她們為基礎創作，或換成自己的角色，不必擔心版權歸屬。

## 打造成你自己的

這個範本的設計讓你不必了解整體運作，也能修改真正重要的部分。

### 你的角色

每個主題都有一位漂浮角色。你可以保留 Crystalline-chan 與 Weltschmerz-chan，也可以換成自己的畫、吉祥物、你家貓咪的照片，或者什麼都不放。理想的角色圖片是背景透明的 PNG，大約 300×450 像素，並且在螢幕角落縮小顯示時依然清楚。水彩、線稿與像素畫都很合適；頁面不會加上外框，你畫的內容會直接漂浮在網站上。

如果不想要角色，任一主題都可以關閉漂浮夥伴，網站其他部分的運作完全不受影響。

### 她的台詞

每位角色都有一組簡短的台詞，會隨機說出，或在訪客點擊時說出。個性大多來自這裡。幾個建議：

- 保持簡短。對話框裡一句話最合適，兩句是極限。
- 配合主題。Crystalline-chan 注意的是光與色彩；Weltschmerz-chan 注意的是重量與寂靜。
- 讓台詞引導方向。像「讓我給你看些閃閃發亮的東西……」這樣的台詞，會引導訪客往下捲動。
- 為隱藏的按鍵序列寫一句台詞。找到它的訪客會看到特別訊息，所以讓它值得被找到。

### 兩個主題，兩種心情

你可以重新命名主題、更改配色，或加入第三個主題。一組對比，例如白天與夜晚、平靜與喧鬧、工作與玩樂，通常比兩套相似的配色更有意圖。無論選擇什麼，都要讓兩個主題中的文字清楚易讀：切換只需點一下，訪客兩個都會看到。

### 會說故事的專案

專案網格有三種檢視：精選、全部專案與實驗性。精選放的是你在面試時最想先展示的作品。實驗性則放那些古怪、未完成卻充滿樂趣、能展現你思考方式的東西；許多訪客覺得這一區最有趣。每個專案可以有多張截圖、標籤、展示連結與原始碼連結，以及卡片用的一行摘要和較長的說明。

### 英文與日文

網站上的每個標籤都有英文與日文版本，訪客可以從頁首切換語言。你的名字、職稱、所在地與簡介也可以準備兩種語言。這讓範本很適合做雙語作品集、在日本求職，或同時向兩種讀者展示作品。

### 終端機

為喜歡鍵盤的訪客，網站內建了一個小型終端機。輸入 `help` 會列出指令；`ls` 列出你的專案，`featured` 與 `experimental` 切換網格，`clear` 清空畫面，`exit` 關閉終端機。這只是個小巧思，但開發者往往會發現並樂在其中。

## 技術堆疊

Next.js 15（App Router，匯出為靜態網站）、React 19、TypeScript、Tailwind CSS 3、Framer Motion，以及 shadcn/ui 風格的 Radix UI 元件與 Lucide 圖示。展示網站架設在 GitHub Pages 上。

## 快速開始

需要 Node.js 18.18 以上，以及 npm 或 pnpm。

1. Clone 儲存庫：
   ```bash
   git clone https://github.com/anime-portfolio/app.git
   cd app
   ```

2. 安裝相依套件：
   ```bash
   npm install
   # or
   pnpm install
   ```

3. 啟動開發伺服器：
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

4. 開啟 [http://localhost:3000](http://localhost:3000)。

### 建置

```bash
npm run build
```

網站會以靜態檔案匯出到 `out/`。若要從子路徑提供服務，例如 GitHub Pages 上的 `/app/`，請在建置時設定 `PAGES_BASE_PATH=/app`。

## 自訂

### 個人資料

編輯 `data/portfolio-data.tsx`：

```typescript
export const profileData: ProfileData = {
  name: {
    en: "Your Name",
    ja: "あなたの名前",
  },
  role: {
    en: "Your Role",
    ja: "あなたの役割",
  },
  // ... more configuration
}
```

社群連結與聯絡信箱皆為選填；頁面只會顯示已設定的項目。

### 專案

在同一個檔案的 `works` 陣列中加入你的專案：

```typescript
{
  id: "your-project",
  title: "Project Title",
  description: "Project description...",
  images: ["image1.jpg", "image2.jpg"],
  link: "https://your-project.com",
  repo: "https://github.com/your-username/project",
  tags: ["React", "TypeScript", "Next.js"],
  date: "2024-12",
  featured: true,
}
```

### 主題

兩個主題位於 `contexts/theme-context.tsx`。新主題就是另一份相同結構的設定，搭配自己的配色與漂浮角色：

```typescript
export const customTheme: PortfolioPageProperties = {
  type: "fullscreen",
  styles: ["anime", "custom"],
  gradientBg: "bg-gradient-to-br from-custom-900 to-custom-100",
  // ... more customization
}
```

## 部署

展示網站透過 `.github/workflows/pages.yml` 部署到 GitHub Pages，每次推送到 `master` 時都會建置並發布網站。匯出的 `out/` 資料夾也能在 Vercel、Netlify 或任何靜態主機上運作。

### 在 GitHub Pages 發布你自己的版本

由於網站匯出為純靜態檔案，架設是免費的，也不需要伺服器：

1. Fork 這個儲存庫，或把它當作範本建立新的儲存庫。
2. 在儲存庫設定中打開 Pages，並選擇 GitHub Actions 作為來源。
3. 推送一個變更到 `master` 分支。內附的工作流程會建置網站，並發布到 `https://your-username.github.io/your-repository/`。

如果你從名為 `your-username.github.io` 的儲存庫發布，網站會位於該網址的根目錄。自訂網域也可以在同一個 Pages 設定中加入。之後每次推送都會自動重新建置並發布，所以更新作品集只需要編輯檔案並推送。

## 常見問題

### 可以免費使用嗎？

可以。程式碼採用 MIT 授權，你可以用於個人網站、客戶專案或商業產品，並任意修改。

### 我可以在自己的網站上使用 Crystalline-chan 與 Weltschmerz-chan 嗎？

可以。角色插畫採用 CC BY 4.0 授權，只要標示出處，就能使用、修改與再散布，包括商業用途。在頁尾或 README 加上一行 "Characters: Crystalline-chan and Weltschmerz-chan by Aesthetic Vulpes (CC BY 4.0)" 即可。

### 需要懂 React 或 Next.js 嗎？

基本使用不需要。你的名字、簡介、連結、專案與角色台詞都放在簡單的資料檔中，讀起來幾乎像一張表單。修改版面或加入新功能則需要一些 React 知識。

### 需要伺服器或資料庫嗎？

不需要。網站匯出為靜態的 HTML、CSS 與 JavaScript，可以免費在 GitHub Pages、Netlify、Vercel、Cloudflare Pages 或任何一般網頁主機上運作。

### 手機上能用嗎？

可以。版面是響應式的，小螢幕上導覽會收合成選單，角色也不會擋住內容。

### 可以拿掉動漫元素，當作一般的作品集嗎？

可以。關閉漂浮角色、選擇較沉穩的配色，剩下的就是一個簡潔快速的開發者作品集，包含專案網格、個人簡介、兩個主題與雙語支援。

### 可以在這裡分享我的作品集嗎？

非常歡迎。請到 [Discussions](https://github.com/anime-portfolio/app/discussions) 分享；看到大家如何把它變成自己的，是維護範本最開心的事。
